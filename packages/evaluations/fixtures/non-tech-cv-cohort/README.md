# Non-tech CV cohort

Four fictional full-CV cases outside software, in the same layout as the
software cohorts: a nurse, an account executive, a primary teacher and an
electrician. Each case has `candidate-profile.md` with evidence ids,
`job-description.md` with numbered requirements, and `expectations.json`.

Each case holds traps the software cohorts lack:

| Case | Traps |
| --- | --- |
| `case-nurse` | ALS booked but not held, occasional nurse-in-charge shifts, a career break, an audit credited to the educator's change |
| `case-sales` | One year above quota and one below, a team close led by the director, a 2nd-place ranking, a workshop that is not a certification |
| `case-teacher` | Results credited to the team and tutoring, a subject lead who is not senior leadership, Key Stage names |
| `case-electrician` | Initial verification but no EICR, 18th Edition ordinal, work under a supervisor, a travel gap |

Everything is invented. No provider run is authorized by these files: the
failure-taxonomy rounds (#1105) need the owner's go and a cost cap, and run
through `scripts/failure-taxonomy-rounds.mjs` as described in
[Failure taxonomy](../../../../docs/evaluation/failure-taxonomy.md).
