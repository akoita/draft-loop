# Backend Engineer, Event Platforms — Pewter Tide Commerce

Pewter Tide Commerce builds order and inventory software for regional
retailers. The Backend Engineer will work with the event-platform group on
reliable services and operational tooling.

## Responsibilities

- [r1] Build and operate production Kotlin or Java services that process asynchronous
  order events.
- [r2] Own retry, idempotency, and replay behavior from design through production
  rollout.
- [r3] Use service metrics and incident learning to improve reliability.
- [r4] Lead a production data-store migration, including its implementation and
  rollout plan.
- [r5] Coordinate technical decisions with product, operations, and customer-facing
  engineering teams.
- [r6] Set technical direction across multiple engineering teams.

## Qualifications

- Demonstrated production backend engineering experience.
- Clear written communication and careful separation of shipped work from
  studies, prototypes, or recommendations.
- [r7] Relevant software systems degree or equivalent experience.
