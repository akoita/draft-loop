# Developer Platform Engineer — Velvet Circuit Software

Velvet Circuit Software builds release tooling for teams that operate
distributed services. The Developer Platform Engineer works on build
orchestration, merge workflows, and the reliability of shared engineering
tools.

## Responsibilities

- [r1] Build and maintain production Go or Python tooling for build and test
  workflows.
- [r2] Own a shared cloud-backed developer service from design through
  operations and incident response.
- [r3] Set technical direction across the engineering organization and mentor
  several teams.
- [r4] Lead implementation and rollout of a production migration to
  object-store-backed artifact handling.
- [r5] Hold a current professional Kubernetes or cloud-platform certification.
- [r6] Use measured build and release outcomes to guide reliability work.

## Qualifications

- Experience shipping useful internal software without overstating individual
  ownership of team outcomes.
- Clear technical writing and evidence of collaboration across functions.
- A computing-related degree or equivalent practical experience.
