# Senior Media Infrastructure Engineer — Dunefold Media Cloud

The team builds media-ingest and delivery services for independent stations.

Requirements:

- [r1] Maintain production ingest and playback-support services.
- [r2] Implement Rust or Java components for validating media manifests.
- [r3] Own CDN configuration, production operations, and on-call response.
- [r4] Measure validator performance on repeatable, bounded media samples.
- [r5] Coordinate delivery rules with station partners and document handoffs.
- [r6] Plan and execute migrations of archived media packages.
- [r7] Set content-protection policy and manage encryption-key custody.
