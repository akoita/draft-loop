# Independent software-engineering cohort

This directory contains two fictional candidates and distinct software
engineering roles. Names, organizations, projects, addresses, and histories
were invented for these fixtures; contact email domains use `.test`.

The author has seen earlier cases C and D, so E and F are not a blind holdout.
Their source expectations describe evaluation questions, not measured outcomes.
Case E states a dated interval with no software role. Case F has separated role
dates but makes no source claim about unemployment during the intervening time.

No provider run is authorized by this fixture. A future run requires separate
admission and authorization. The planned ceiling is one ordinary author–critic
round per case and four provider calls total.
